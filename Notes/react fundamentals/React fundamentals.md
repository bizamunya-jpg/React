# What is React
- React is a javascript library used to build user interfaces
-  React helps us organize the user interface into smaller reusable pieces
- instead of building my entire website as one giant piece, i' ll divide it into smaller pieces

# Think ABOUT LEGO
- imagine building a house using lego.
- instead, you have:
1. walls
2. Windows
3. Doors
4. Roof
- React works in the same way.
- Hence a website can be divided into components.

# What is a Component?
- A component is a reusable piece of a user interface.
- Think of a component as a small building block.
for example :

StudentCard
-----------
Name: John 
Age: 20
Course: Computer Science
-----------
instead of writing the sam HTML again and agian for every student, we can create one StudentCard component and reuse it.
